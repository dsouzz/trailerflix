# 🎬 Movie Catalog

Movie Catalog é um catálogo interativo de filmes desenvolvido utilizando HTML, CSS e JavaScript.

Inspirado na experiência de navegação de plataformas de streaming, o projeto foi criado para organizar títulos de forma visual e intuitiva, permitindo pesquisar filmes e acessar seus trailers oficiais.

---

## ✨ Funcionalidades

- 🎬 Catálogo organizado de filmes
- 🔍 Pesquisa em tempo real
- 📱 Interface responsiva
- 🎨 Layout inspirado em plataformas de streaming
- 🎥 Acesso rápido aos trailers oficiais
- ⚡ Navegação simples e intuitiva

---

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

---

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de praticar desenvolvimento front-end, criação de interfaces modernas e manipulação dinâmica de elementos utilizando JavaScript.

Além disso, serviu como estudo de organização de conteúdo e experiência do usuário em aplicações web.

---

## ⚠️ Aviso

Este projeto **não hospeda, distribui ou transmite filmes**.

Todos os conteúdos apresentados têm caráter demonstrativo, e os links disponibilizados direcionam apenas para materiais públicos, como trailers oficiais, quando disponíveis.

---

## 🚀 Executando

Basta abrir o projeto em um navegador moderno ou acessar a versão publicada.

---

## 📚 Aprendizados

Durante o desenvolvimento foram explorados conceitos como:
